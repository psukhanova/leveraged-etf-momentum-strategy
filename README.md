
# Leveraged ETF Momentum Trading Strategy

## Project Overview
This project develops and backtests a 20-day momentum trading strategy across five international leveraged ETF markets using Python. The objective is to evaluate momentum-based investment performance and assess whether the strategy generates statistically significant risk-adjusted returns.

## Methodology
- Implemented a 20-day lookback period with a one-month holding period.
- Evaluated strategy performance using cumulative wealth and Sharpe ratios.
- Applied CAPM regressions to assess alpha and market risk exposure.
- Compared strategy performance across five international markets.

## Key Findings
- Four of five markets generated positive returns.
- CAPM regressions did not identify statistically significant alpha.
- The findings highlight the importance of assessing risk-adjusted performance rather than relying solely on positive returns.

## Tools and Techniques
- Python
- Momentum Strategy Backtesting
- Financial Data Analysis
- Sharpe Ratio and CAPM
- Statistical Regression Analysis
